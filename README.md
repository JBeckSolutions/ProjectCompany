Spielstart: 
 - Einzelspieler:
   
    Im Hauptmenü wird der Button „Host“ betätigt und in der Lobby auf „start game“ gedrückt, um das Spiel zu starten. 
  
 - Mehrspieler (lokales Netzwerk) - getestet:
   
    Ein Spieler öffnet zu Beginn eine Lobby über den Hauptmenü-Button „Host“. Weitere Spieler drücken im Hauptmenü die „Join“ Taste und geben die IP-Adresse, welche oben beim Host in der geöffneten Lobby steht, ein.
    Sobald alle Spieler in der Lobby sind, kann der Host das Spiel über den Button „start game“ beginnen. 
  
 - Mehrspieler Variante 1 (globales Netzwerk) - ungetestet:
   
    Der Host öffnet den Port „7777“ über seinen Router. 
    Ein Spieler öffnet zu Beginn eine Lobby über den Hauptmenü-Button „Host“. Weitere Spieler drücken im Hauptmenü die „Join“ Taste und geben die öffentliche IPv4-Adresse des Hosts ein (https://whatismyipaddress.com/).
    Sobald alle Spieler in der Lobby sind, kann der Host das Spiel über den Button „start game“ beginnen. 
  
 - Mehrspieler Variante 2 (globales Netzwerk) - ungetestet:
   
    Alle Spieler verbinden sich über ein VPN-Programm miteinander, wie beispielsweise über Hamachi. 
    Ein Spieler öffnet zu Beginn eine Lobby über den Hauptmenü-Button „Host“. Weitere Spieler drücken im Hauptmenü die „Join“ Taste und geben die IPv4-Adresse des Hosts im VPN-Programm an.
    Sobald alle Spieler in der Lobby sind, kann der Host das Spiel über den Button „start game“ beginnen.


   
Spielweise: 
1. Runde wird in der Laborzelle über den Knopf gestartet 
2. In der zufallsgenerierten Karte werden Wertgegenstände gesammelt und zum Startraum gebracht, um die Quote am Bildschirm zu erfüllen.   
    Besonderheiten:
     - Gegenstände können nur aufgehoben werden, wenn der aktive Inventarplatz 
      leer ist 
     - Gegenstände haben ein Gewicht -> falls viel getragen wird, wird die Bewegung eingeschränkt 
     - Große Gegenstände verbrauchen mehrere Inventarplätze 
4. Während der Runde sollte auf Gegner geachtet und diesen aus dem Weg gegangen werden 
5. Bei Erreichen der Quote wird zum Abschluss der Knopf zur Rückkehr gedrückt 
6. Eine neue Runde mit höherer Quote kann in der Laborzelle gestartet werden



Kreaturen: 
- Stalker -> Anstarren führt zu Angriff des Monsters. Ein kurzer Blick auf kleiner Distanz schlägt ihn in die Flucht
- Kidnapper -> Durch Staubwolken erkennbar. Nicht tödlich. Trägt den Spieler zu einem zufälligen Punkt auf der Karte 
- Security-Roboter -> Erkennbar an rotem Licht. Bei Sichtung des Spielers nimmt dieser die Verfolgung auf und attackiert, wenn in Reichweite
